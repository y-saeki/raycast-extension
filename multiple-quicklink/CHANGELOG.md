# Multiple Quicklink Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Multiple Quicklinks: open a saved set of links with one keystroke, and create, edit, duplicate or delete sets
- A set may mix web URLs, local files and folders, and `raycast://` deeplinks, opened in the order they are written
- Any single link can name the application it opens in
- Create Quicklink for This Set turns a set into a native Quicklink, so it gets a root search entry, an alias and a hotkey
- Open Multiple Quicklink opens a set by name, which is what a Quicklink or deeplink lands on
- Links open one at a time, in order, and a link that fails does not stop the rest
- Runs on both macOS and Windows
